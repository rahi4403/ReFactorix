# ReFactorix — Autonomous Legacy Code & Security Modernization Agent

> Production-grade, premium web application dashboard for autonomous legacy code deconstruction, multi-manifest vulnerability scanning, interactive AST architectural mapping, and mathematical syntax guardrail verification.

Designed strictly following the **RaDe Creatives AI/ML Guard** enterprise UI template.

---

## 🛠 Features & Capabilities

### 1. Theme Switcher (Persistent)
- **Dark Mode**: Deep obsidian midnight aesthetic (`#080C14`), glowing molten amber-orange accents (`#FF5B26`), electric cyan hints, and frosted glass panels.
- **Light Mode**: Clean enterprise off-white (`#F8FAFC`), crisp typography, high-contrast borders, and warm accents.
- **System Mode**: Dynamically follows your operating system's color scheme with persistent `localStorage` synchronization.

### 2. Global Navigation / Tabs
- **Dashboard (Overview & Repo Ingestion)**:
  - Dynamic 3D cyber wave ribbon canvas matching the template hero.
  - Public GitHub repository URL ingestion input (`https://github.com/...`) with live execution stepper.
  - Quick-select sample codebases (Built-in multi-manifest demo repository, `psf/requests`, `pallets/flask`).
  - Core Modernization Engine showcase (AIQu VEIL inspired), 4 Key Pillars, and 3 Pipeline Security Architecture layers.
  - Executive KPI metrics (Vulnerabilities, AST Nodes, Guardrail Pass Rate, Supported Ecosystems).
- **Archaeologist Audit (Vulnerability & Manifest Scanner)**:
  - Multi-format scanning across Python (`requirements.txt`), Node.js (`package.json`), Java Maven (`pom.xml`), and multi-language code anti-patterns (`eval(`, `urllib2`, `CGIHTTPServer`, `document.write`, `var `).
  - Ecosystem and Severity filters (Critical, High, Medium).
  - Instant live search bar and expandable inspection modal drawer with remediation strategies.
- **AST Code Structure (Interactive Architectural Node Map)**:
  - Interactive Force-Directed Graph rendering node-based relationship maps for classes (`ast.ClassDef`) and functions (`ast.FunctionDef`).
  - Zoom, pan, drag physics, class/function filters, and search.
  - Real-time AST Node Inspector showing code signatures and line locations.
- **Refactoring & Guardrail Sandbox (Live Code Diff & Safety Validator)**:
  - Side-by-side comparison cards (Original Legacy Snippet vs Modernized Secure Code Patch).
  - Live AST Validation status badge (Passed / Failed) powered by Python 3.12 `ast.parse`.
  - Live editable code sandbox with real-time syntax checking as you type.
  - RFC-compliant unified diff output (`difflib.unified_diff`) with addition/deletion styling and one-click copy.
  - 5 pre-loaded presets including the canonical SQL query test, dynamic `eval()`, deprecated `urllib2`, JavaScript `var`/`document.write`, and intentional syntax error testing.
